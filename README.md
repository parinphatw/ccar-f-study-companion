# CCAR-F Study Companion

An unofficial, independent study companion for Claude Certified Architect Foundations. Original chapters, fictional scenarios, recall questions, worked answers, and an objective coverage map. Not affiliated with or endorsed by Anthropic. No promise of exam results.

Read: https://parinphatw.github.io/ccar-f-study-companion/

## Build

Requires mdBook 0.5.4 (MPL-2.0): https://github.com/rust-lang/mdBook/releases/tag/v0.5.4

Run `mdbook build` from this directory. Output is committed to `docs/` for GitHub Pages branch publishing. Keep `docs/.nojekyll` after rebuilding. Run `mdbook serve` for local preview. No analytics, login, or backend.

## Content and sources

See the Sources and further reading chapter for attribution and version caveats. The official exam PDF is linked, not redistributed. No external guide prose, diagrams, or code are copied into the chapters. Public access alone is not a grant of a new license for third-party content.
